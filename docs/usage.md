# Usage Guide

This guide provides a detailed overview of how to use the application.

## Uploading a Dataset

1. Click on the 'Upload Dataset' button.
2. Select a dataset file (.csv, .xlsx, etc.).
3. Click on the 'Upload' button.

## Exploring Visualization Options

1. Click on the 'Visualize' button.
2. Select a visualization type (e.g., bar chart, line chart, etc.).
3. Customize the visualization options as desired.
